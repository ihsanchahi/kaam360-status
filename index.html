How this works: a small program hosted with GitHub asks kaam360.com/health (which also tests the database) and the sign-in page every 5 minutes. A check counts as down when there is no good answer within 20 seconds, twice in a row. Incidents are written by the Kaam360 team. Email alerts are sent from the main Kaam360 server, so while that server itself is down they go out once it is back.
